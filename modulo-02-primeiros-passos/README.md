# Módulo 02 — Primeiros Passos no React

## Foco
1. Componente + props: componente reaproveitável que recebe dados diferentes.
2. Renderização condicional: ternário e `&&` (cuidado: `{0 && <X />}` mostra "0" na tela).
3. Listas com `map` + `key` estável (id, nunca o índice).
4. `children` (`React.ReactNode`): componente que "embrulha" outros.
