# Módulo 01 — Introdução e Instalação

## Foco
1. A tela é um reflexo do estado: muda o dado, o React atualiza a tela.
2. Virtual DOM: o React compara a versão nova com a anterior (reconciliação) e aplica no DOM real só o que mudou.
3. Pensar em reactês: dividir a tela em componentes, decidir onde cada dado fica, dados descem do pai para o filho.
