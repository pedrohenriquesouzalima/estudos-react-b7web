# Estudos React — B7Web

Repositório de estudos do curso de React da B7Web (React + TypeScript + Tailwind, com Vite e Next.js).

> Exercícios guiados pelo curso — não são projetos autorais de portfólio. O objetivo aqui é registrar a evolução e a constância nos estudos.

## Estrutura

Cada módulo tem uma pasta com:
- os exercícios do módulo (um projeto por subpasta);
- um `README.md` com os pontos principais e as perguntas de entrevista, respondidas com as minhas palavras.

| Módulo | Tema | Status |
|---|---|---|
| 01 | Introdução e Instalação | ⏳ |
| 02 | Primeiros Passos no React | ⏳ |
| 03 | Estados e Eventos | ⏳ |

## Método

1. Assistir à aula e fazer junto com o professor.
2. Refazer o exercício do zero, sem assistir de novo.
3. Responder as perguntas de entrevista do módulo antes de seguir.
